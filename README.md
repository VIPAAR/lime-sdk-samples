# Sample Apps of Help Lightning SDK

## SamplePresence

The unified sample app for Help Lightning SDK integrations on iOS and visionOS.
It includes four runnable targets: iOS SwiftUI, iOS UIKit (Swift), iOS UIKit (ObjC), and visionOS SwiftUI.
See `[SamplePresence/README.md](SamplePresence/README.md)`.

## SampleObjC (deprecated)

Frozen legacy Objective-C sample (CocoaPods / HLSDK 17.x).
Superseded by `SamplePresence` (`SamplePresence-iOS-UIKit-ObjC` scheme).
See `[SampleObjC/README.md](SampleObjC/README.md)`.

## SampleSwift (deprecated)

Frozen legacy UIKit (Swift) sample (CocoaPods / HLSDK 17.x).  
Superseded by `SamplePresence` (`SamplePresence-iOS-UIKit` scheme).  
See `[SampleSwift/README.md](SampleSwift/README.md)`.
