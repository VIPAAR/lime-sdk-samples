# SampleSwift (deprecated)

> **Deprecated and frozen.** Do not use this project as a starting point for new integrations.
>
> Use **`SamplePresence`** instead — specifically the
> **`SamplePresence-iOS-UIKit`** scheme.
>
> See [`../SamplePresence/README.md`](../SamplePresence/README.md).

This directory is retained only as a historical reference for the older
CocoaPods-based UIKit (Swift) sample (HLSDK 17.x, iOS 14+).

It is **not** updated for current SDK releases, SPM packaging, screen-sharing
extensions, or the Presence call-configuration APIs. Source, Podfile, and
Xcode project files here are frozen.
